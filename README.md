# Collective Insight

Landing site for the Collective Insight framework. Static HTML, no build step.

## Publish with GitHub Pages

1. Create a repository (for example `collective-insight`) and add these files at the root.
2. Add your proposal as `proposal.pdf` in the same folder (the "Read the proposal" button links to it).
3. In the repository, go to Settings, then Pages. Under Source choose "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. Your site goes live at `https://<your-username>.github.io/collective-insight/` within a minute or two.

## Custom domain

Add a file named `CNAME` containing your domain (for example `collectiveinsight.org`), then point the domain's DNS at GitHub Pages as described in the GitHub docs.

## Before you share it

- Replace the placeholder text in the About section and the contact email.
- Add `proposal.pdf`, or change the button's link.
